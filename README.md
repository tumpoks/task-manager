# Task Manager

A simple Task Manager CRUD application built for an internship assessment using Laravel and Vue.js.

## Features

- Create tasks
- View existing tasks
- Edit tasks
- Delete tasks with confirmation
- Set task status to Pending or Completed
- Add an optional task description
- Add an optional due date
- Server-side validation
- Success and error messages
- RESTful API endpoints

## Technologies Used

- Laravel 13
- PHP 8.4
- Vue.js 3
- TypeScript
- Vite
- SQLite
- Tailwind CSS
- Fetch API

## Requirements

Before running the project, make sure the following are installed:

- PHP 8.4 or later
- Composer
- Node.js and npm
- Git
